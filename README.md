Калькулятор квадратных уравнений
Данная программа вычисляет корни квадратного уравнения через дискриминант и возвращает правильный ответ.
для работы мы используем две функции:
1) функция discriminant(a, b, c) - расчет самого дискриминта
2) функция solution(a, b, c) - проверки дискриминанта и прасчет корней уравнений
